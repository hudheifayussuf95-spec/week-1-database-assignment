-- Introduction & Database Landscape Quiz

-- Q1: What is the main advantage of a database over storing data in a plain text file?
-- A: Databases support concurrent access, fast indexed lookups,
--    data integrity rules, and crash recovery.

-- Q2: Which database family would best store and query "friends-of-friends" relationships in a social network?
-- A: Graph (Neo4j)

-- Q3: What does the "D" in ACID guarantee?
-- A: Durability - committed data survives crashes and power loss.

-- Q4: A team needs a blazing-fast cache for user session data that can expire automatically. Which tool fits best?
-- A: Redis

-- Q5: What does "polyglot persistence" mean?
-- A: Using multiple database types together, each for the job it does best.
